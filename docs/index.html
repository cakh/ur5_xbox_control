Xbox Controller Robot Jog

Drive a UR or Meca500 robot arm with an Xbox controller from a Windows PC.

1 Install 2 Get the code 3 Packages 4 Controller 5 Robot 6 Run Controls Troubleshooting
There is no enable button. Sticks, triggers and bumpers move the robot the instant you touch them. Keep the e-stop within reach, keep people clear of the arm, and always do a --dry-run first.

This guide assumes you already know the robot (pendant, Remote Control, e-stop, IP setup) but have never used GitHub or a code project before. Follow the steps in order; each one takes a few minutes. You only do steps 1–3 once per PC.

UR: on the pendant, Menu → Settings → System → Network. Otherwise see your cell documentation or integrator. Every robot is different.

2 Get the code

A repo (repository) is just a project folder that Git keeps in sync with GitHub. Cloning means downloading your own copy of it.
  1. Open VS Code. Press Ctrl+Shift+P, type Git: Clone, press Enter.
  2. Paste this address, press Enter: 
    https://github.com/nickarmenta/robot_xbox_control
  3. Sign in to GitHub in the browser if asked.
  4. Choose a folder to keep it in (for example C:\Users\<you>\source), then click Open when VS Code offers.
  5. If VS Code asks "Do you trust the authors?", click Yes, I trust.

No Git? Open the repo page, click the green Code button → Download ZIP, extract it, then in VS Code use File → Open Folder. You won't get updates this way.

3 Install the Python packages

In VS Code open a terminal: Terminal → New Terminal (or Ctrl+`). It opens in the project folder. Run these one line at a time:

# use -3.11 if that's the version you installed
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

You should now see (.venv) at the start of the terminal line. If VS Code asks to use the new environment for the workspace, click Yes. In any new terminal, run .venv\Scripts\Activate.ps1 again if (.venv) is missing.

4 Connect the controller

  1. Plug in the Xbox 360 wireless receiver (or a wired controller) and press the controller's Guide button.
  2. Press Win+R, type joy.cpl, Enter. Your controller should be listed. Open Properties and move the sticks to confirm.
  3. Receiver shown as an unknown device? Install Xbox 360 Wireless Receiver for Windows from Windows Update or the Microsoft Update Catalog.

5 Prepare the robot

  1. Power on, release the brakes, and switch the pendant to Remote Control (e-Series).
  2. Give your PC a static IP on the robot's network: same first three numbers as the robot, a different last number, subnet mask 255.255.255.0.
    Windows: Settings → Network & internet → Ethernet → IP assignment → Edit → Manual.
  3. Test it in the VS Code terminal: 
    ping <ROBOT_IP>
    You want replies, not "Request timed out".
  1. Power on the Meca500.
  2. Give your PC a static IP on the robot's network (same first three numbers, different last number, mask 255.255.255.0).
  3. Close MecaPortal and anything else connected to the robot. Only one control connection is allowed.
  4. Test it: 
    ping <ROBOT_IP>

6 Run it – always in this order

A. Test the controller

cd src
python xbox/xbox_control.py

Move the sticks and triggers: the numbers on screen should change. Press Ctrl+C to quit.

B. Dry run – robot does NOT move

UR:

python main.py --ip <ROBOT_IP> --dry-run

Meca500:

python meca_main.py --ip <ROBOT_IP> --dry-run

It connects, reads the robot's pose and prints what it would send. If a Windows Firewall popup appears, tick Private networks and click Allow access.

C. Live

Robot will move. Clear the work area, hand on the e-stop.

UR:

python main.py --ip <ROBOT_IP>

Meca500:

python meca_main.py --ip <ROBOT_IP>

The Meca500 script clears errors, activates and homes the robot on start. Homing moves the joints, so it asks for confirmation first (--yes skips the question). If a dropped connection left the robot paused, it resumes.

To stop

  • Press Back on the controller, or Ctrl+C in the terminal.
  • Emergency: the pendant e-stop. Closing the terminal also stops the program.

Troubleshooting

Click a problem to see the fix.

"python" is not recognized, or it opens the Microsoft Store
Reinstall Python with Add python.exe to PATH ticked, or turn off Settings → Apps → Advanced app settings → App execution aliases for python.exe. The py command works even without PATH.
"Activate.ps1 cannot be loaded because running scripts is disabled"
Run this once, then activate again: 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
pip install fails on ur_rtde
Python 3.13 and newer have no Windows package for it. Install Python 3.11 or 3.12, delete the .venv folder, and redo step 3.
"ModuleNotFoundError: rtde_control"
The virtual environment isn't active (no (.venv) in the terminal line) or step 3 was skipped. Run .venv\Scripts\Activate.ps1, then pip install -r requirements.txt.
"WARNING: no controller detected", or the controller test shows nothing
Check joy.cpl. Press the Guide button, replace the batteries, re-plug the receiver, and close other apps that may be using the controller.
Windows Firewall popup, or the connection times out
On the popup tick Private networks and click Allow access. If it was dismissed or you don't have admin rights, connections will time out: ask IT to allow python.exe on private networks. Also check ping <ROBOT_IP>, your PC's static IP and subnet, and turn off VPN or Wi-Fi that may be taking the route.
UR connects but shows RTDE errors
The pendant isn't in Remote Control, the brakes aren't released, or another RTDE client is connected.
Meca500 refuses the connection
MecaPortal or another client is still connected. Close it.
"ERROR ... Press Start"
A protective stop, safety mode or failed command. Fix the cause, then press Start on the controller. Start never releases brakes or restarts safety: after an e-stop you need a physical reset on the pendant.
Dry run prints commands but the robot doesn't move
That's what --dry-run does. Run the same command without it.
Robot won't move any further in one direction
You reached the workspace limit (see Safety below). If the arm starts outside the allowed area, only motion back inside is allowed.
An axis moves the wrong way
Flip the matching sign_* value in src/ur_control/jog.py (UR) or src/meca_control/jog.py (Meca500). Ask before changing other settings.
The X button does nothing (UR)
Gripper control needs the Robotiq URCap installed and the gripper activated on the pendant. Without the URCap there is no gripper control: ignore X.
The robot stops by itself
By design: commands stopped arriving (0.1 s timeout), the controller disconnected, or a fault occurred.

Still stuck? Copy the full terminal output (red text and all) and send it along with what you were doing.

Getting updates

In VS Code click the Source Control icon in the left bar, then … → Pull. Or in the terminal: git pull. If Git complains about local changes, ask before forcing anything.

Safety behavior

UR

  • Workspace (base frame): X −0.400..−0.100 m, Y −0.300..−0.100 m, Z ±0.30 m around the start pose, 10 mm stand-off. If the arm starts outside, only motion back inside is allowed.
  • Tool Z is held within 30° of straight down (about 27° reachable: 3° margin, and tilt speed tapers earlier the faster you go). Tilt speed tapers to zero near the limit; spin about tool Z (bumpers) is unrestricted. Y re-aligns to vertical.
  • Velocity is shaped in software at 0.8 m/s² per axis, so stopping distance is known and the limits hold (verified in a closed-loop simulation with random inputs). track_accel (3.0) is how tightly the robot follows, and how fast it stops if commands stop arriving (0.1 s timeout). Controller disconnect = zero velocity.
  • Faults (protective stop, safety mode, dead RTDE script, failed command) halt motion and print ERROR ... Press Start.
  • The pendant speed slider and safety configuration still apply.
  • Tune in src/ur_control/jog.py (JogConfig).

Meca500

  • 50 mm/s max (10 fine), 200 mm/s² slew. Default box ±100 mm around the start pose; change with --workspace XMIN YMIN ZMIN XMAX YMAX ZMAX.
  • SetVelTimeout(0.1) stops the robot if commands stop. A stale pose or any robot error halts until Start.
  • Tune in src/meca_control/jog.py.
